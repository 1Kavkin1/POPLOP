QuizApp - WPF + EF Core (SQLite)

1. Відкрийте QuizApp.sln у Visual Studio 2026.
2. Переконайтеся, що встановлено .NET 10 SDK (робоче навантаження ".NET desktop development").
3. Натисніть F5.

Файл бази quiz.db створюється в папці bin поруч із виконуваним файлом.
Щоб почати з нуля, видаліть quiz.db.
